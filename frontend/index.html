Professional Profile

Pranav Shende is a Full Stack Developer and Forward Deployed Engineer based in Nagpur, India. He specializes in backend engineering, AI-powered applications, enterprise software, Retrieval-Augmented Generation (RAG), and scalable system architecture.

His engineering work includes enterprise intelligence platforms (Jarvis AI), clinical AI systems (Electropathy AI), distributed food delivery logistics (Tastifyy), civic governance applications (JanSampark), clean-tech big data analytics (Solar Intelligence), and edge veterinary diagnostics (PashuRakshak).

His technical ecosystem includes React 19, Node.js, PostgreSQL, Python, Prisma ORM, Fastify, Supabase, Apache Kafka, Redis, Model Context Protocol (MCP v1.0.4), pgvector, and Google Gemini 2.5 Pro/Flash.
